What happens next

This page cannot control ttdevasthanams.ap.gov.in directly — browsers block a page from reaching into another website. The steps below are done by the companion script, ttd_booking_assist.py, which runs on your own computer.
  1. Log in yourself in the browser window the script opens (mobile + OTP). manual
  2. Open the Differently Abled / Sr. Citizen Darshan booking flow. auto
  3. Wait through the virtual queue — the script polls for you, no need to babysit it. auto
  4. Select Category = Senior Citizen, fill Age and "Accompany with Spouse". auto
  5. Pick your date and confirm the time slot yourself on the calendar. manual
  6. Fill Pilgrim Details (name, age, gender, ID type/number) and upload your ID photo from the config. auto
  7. Review and click the final Submit/Book button yourself. manual

Steps 1 and 5 stay manual on purpose: login needs your OTP, and the date/time pick is the fair, first-come part of a high-demand quota that many other senior citizens are also waiting on — that shouldn't be automated. The final submit (step 7) also stays manual since this script hasn't been tested against the live site. 

pip install playwright
playwright install chromium
python ttd_booking_assist.py

Place the downloaded ttd_config.json in the same folder as the script before running it.
